# ДЗ 7. Квантизация и дистилляция Qwen3

[Ноутбук](homework_compression_student.ipynb) · [Отчёт](EXPERIMENTS.md)

Я запускал ноутбук на Python 3.12 с одной A100 на 80 ГБ. В новом окружении раскомментируйте установку библиотек в первой ячейке кода, запустите её и перезапустите ядро. Затем выполните все ячейки по порядку. Ноутбук скачает данные и исходные модели с Hugging Face.

[Оба чекпоинта на Яндекс Диске](https://disk.360.yandex.com/d/2xZZVhtH5oqi7w)

**Qwen3-8B AWQ** · [Конфигурация](artifacts_compression_hw/awq_massive/config.json) · [Метрики](artifacts_compression_hw/awq_massive_dev.json)

Я сжал веса Qwen3-8B до 4 бит с группой 128. Активации остались 16-битными. Для калибровки взял 64 русских запроса из MASSIVE. На 256 запросах dev модель получила Q = 0,387.

**Обученный ученик** · [Метрики](artifacts_compression_hw/student_dev.json)

В архиве ученика лежит LoRA-адаптер для Qwen3-8B. Его Q на той же выборке — 0,593. Чтобы открыть сохранённые модели из ноутбука, распакуйте оба архива в `artifacts_compression_hw/`.
